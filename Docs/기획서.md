# 🚀 해커톤 통합 관리 플랫폼 'Hackathon Hub' 기획서

## 1. 서비스 개요
본 프로젝트는 해커톤의 전 과정을 관리하고 참가자들의 협업을 지원하는 **원스톱 해커톤 매니지먼트 플랫폼**입니다. 기존의 파편화된 해커톤 운영 방식을 하나의 서비스로 통합하여 참가자들이 프로젝트 개발에만 집중할 수 있는 환경을 제공합니다.

### 1.1 목표
- 해커톤 정보 제공부터 팀 빌딩, 협업, 제출, 결과 확인까지 통합된 UX 제공
- `localStorage` 기반의 독립적인 데이터 환경 구축으로 서버 없이도 완벽한 기능 수행
- 모던하고 미려한 UI/UX를 통한 사용자 참여 독려

---

## 2. 주요 기능 명세

### 2.1 공통 기능 (Core)
- **최고의 UI/UX:** `Tailwind CSS`와 `Framer Motion`을 활용한 부드러운 애니메이션과 다크 모드 기반의 프리미엄 디자인
- **사용자 인증 (SIMULATED):** 별도의 서버 없이 `localStorage` 기반으로 구현된 로그인/회원가입 시스템
- **통합 알림 창:** 실시간 활동 내역 및 공지사항을 확인할 수 있는 Floating Action Button 형태의 알림 센터

### 2.2 메인 서비스 (Main Pages)
- **메인 대시보드 (`/`):** 서비스의 핵심 메뉴(해커톤, 팀 모집, 랭킹)로 즉시 이동할 수 있는 비주얼 카드 제공
- **해커톤 상세 정보 (`/hackathons/:slug`):**
  - **7대 핵심 섹션:** 개요, 일정/상금, 평가기준, 소속 팀 목록, 결과물 제출, 실시간 리더보드
  - **제출 시스템:** 파일 업로드 및 링크 제출 기능 지원
- **팀 빌딩 라운지 (`/camp`):** 해커톤별 팀 모집 공고 등록, 포지션별 필터링, 오픈채팅 연동
- **명예의 전당 (`/rankings`):** 전체 사용자 활동 점수 기반의 랭킹 시스템 (기간별 필터링 제공)

### 2.3 확장 기능 (Advanced Features - **Reverse Engineered**)
- **팀 전용 워크스페이스 (`/workspace`):**
  - **대시보드:** 팀 소개, 멤버 현황, 다가오는 일정 및 최근 아이디어 요약
  - **아이디어 보드:** 팀원 간 자유로운 브레인스토밍 및 실시간(Storage-based) 아이디어 공유
  - **팀 캘린더:** 해커톤 일정에 맞춘 팀 내부 스케줄링 및 시간별 일정 관리
  - **리소스 저장소:** 협업에 필요한 파일, 링크 등을 카테고리별(파일/링크/기타)로 보관
- **개인 마이페이지 (`/mypage`):**
  - **프로필 관리:** 닉네임 변경, 프로필 공개/비공개 설정
  - **활동 내역:** 참여 중인 해커톤, 소속 팀 현황, 최근 제출물 관리
  - **활동 통계:** 포인트 및 레벨 시스템을 통한 사용자 게이미피케이션 요소 도입

---

## 3. 시스템 아키텍처 (Technical Stack)

| 구분 | 기술 스택 |
| :--- | :--- |
| **Frontend Core** | React 18, Vite, TypeScript |
| **Styling** | Tailwind CSS, Lucide React (Icons) |
| **Animation** | Framer Motion |
| **Data Storage** | Browser `localStorage` (No-Backend Architecture) |
| **Deployment** | Vercel (Automatic CI/CD) |

---

## 4. 사용자 흐름 (User Flow)

1. **온보딩:** 메인 페이지에서 현재 진행 중인 인기 해커톤 확인
2. **참가 결정:** 해커톤 상세 페이지에서 일정 및 상금 확인 후 참여 의사 결정
3. **팀 빌딩:** '팀 모집 라운지'에서 팀을 구성하거나 기존 팀에 합류
4. **협업 수행:** '팀 워크스페이스'에서 일정 관리, 아이디어 공유, 리소스 보관 수행
5. **최종 제출:** 해커톤 상세 페이지의 '제출' 탭을 통해 결과물 업로드
6. **결과 확인:** '랭킹' 및 '리더보드'에서 순위 확인 및 보상(포인트) 획득

---

## 5. 기대 효과
- **운영 효율성:** 파편화된 툴 사용을 방지하여 운영진과 참가자의 커뮤니케이션 비용 감소
- **협업 시너지:** 워크스페이스 기능을 통해 팀 내 결속력 강화 및 개발 생산성 향상
- **확장성:** 향후 백엔드(Supabase/Firebase) 연동을 통해 대규모 동시 접속 서비스로 즉시 전환 가능
