## 1. 프로젝트 개요

### 1.1 서비스 이름
**LinkTon (링크톤)** - 해커톤 탐색부터 팀 빌딩, 협업, 제출까지 모든 과정을 연결(Link)하는 해커톤 통합 플랫폼

### 1.2 개발 배경
본 프로젝트는 **"월간 해커톤: 긴급 인수인계 해커톤"**에 참여하기 위해 개발되었습니다. 해커톤의 요구사항은 다음과 같았습니다:

- **제공된 자료**: `/data` 폴더에 포함된 명세서, UI 플로우, 예시 데이터
- **개발 방식**: 바이브 코딩(Vibe Coding)을 활용한 웹페이지 구현
- **기술 제약**: 서버 없이 브라우저 localStorage 기반으로 동작
- **목표**: 기본 구현 + 팀 고유의 아이디어 확장

### 1.3 서비스 핵심 가치
기존 해커톤 생태계의 문제점을 해결하는 **원스톱 해커톤 매니지먼트 솔루션**:

| 기존 문제 | Link-Ton의 해결책 |
|----------|------------------|
| 해커톤 정보가 여러 사이트에 분산 | 통합 해커톤 목록 페이지 제공 |
| 팀 빌딩을 위해 외부 채널 이용 (오카, 디코) | 내장된 팀 모집 라운지 (Camp) |
| 협업 도구가 파편화 (Notion, Slack, Discord) | 팀 전용 워크스페이스 (아이디어 보드, 캘린더, 리소스) |
| 제출 절차가 복잡하고 불명확 | 통합 제출 시스템 및 실시간 리더보드 |
| 개인 활동 내역 관리 어려움 | 마이페이지에서 통합 관리 + 포인트 시스템 |

## 2. 기획 의도 및 방향성

### 2.1 /data 폴더 분석 결과

#### 📄 `사진 설명.txt` - 핵심 요구사항
제공된 명세서를 분석한 결과, **필수 구현 사항**은 다음과 같습니다:

**[ 공통 요구사항 ]**
- 모든 페이지에서 접근 가능한 GNB (Global Navigation Bar)
- 로딩, 빈 상태, 에러 상태 UI 처리
- localStorage 기반 데이터 관리

**[ 필수 페이지 ]**
1. **메인 페이지** (`/`): 3가지 주요 기능으로 연결되는 대시보드
2. **해커톤 목록** (`/hackathons`): 진행 상태/태그별 필터링 지원
3. **해커톤 상세** (`/hackathons/:slug`): ⭐ **7대 핵심 섹션 필수**
   - 개요/안내
   - 일정/상금
   - 평가 기준
   - 팀 목록 (Teams) - 초대/수락/거절 기능
   - 제출 (Submit) - 파일 업로드, 메모 입력
   - 리더보드 (Leaderboard) - 실시간 순위
4. **팀원 모집 페이지** (`/camp`): 팀 생성, 검색, 필터링
5. **랭킹 페이지** (`/rankings`): 사용자 포인트 순위 (기간별 필터)

#### 🖼️ `Hackathon-UI-Flow.png` & `memo.png`
- UI/UX 플로우 다이어그램 제공
- 화면 전환 흐름 및 사용자 인터랙션 정의

#### 📊 `예시자료/` - JSON 샘플 데이터
| 파일명 | 용도 | 핵심 필드 |
|--------|------|----------|
| `public_hackathons.json` | 해커톤 목록 | slug, title, status, tags, period |
| `public_teams.json` | 팀 정보 | teamCode, name, isOpen, lookingFor |
| `public_hackathon_detail.json` | 해커톤 상세 | sections (7개 섹션 구조) |
| `public_leaderboard.json` | 리더보드 | entries (rank, teamName, score) |

### 2.2 기획 방향성

#### 전략 1: 필수 요구사항 충실 이행
- **7대 섹션 완전 구현**: Overview, Info, Eval, Schedule, Prize, Teams, Submit, Leaderboard
- **필터링 및 검색**: 모든 리스트 페이지에 다중 필터 적용
- **실시간 동기화**: localStorage 변경 시 `storage-update` 이벤트로 전역 업데이트

#### 전략 2: 차별화된 확장 기능 추가
명세서 요구사항을 넘어 **실제 해커톤 참가자의 니즈**를 반영:

**[ 확장 기능 1 ] 팀 전용 워크스페이스**
- **아이디어 보드**: 팀원 간 브레인스토밍 (카드 형태, 실시간 공유)
- **팀 캘린더**: 해커톤 타임라인에 맞춘 일정 관리
- **리소스 저장소**: GitHub, Figma, 문서 링크 통합 관리

**[ 확장 기능 2 ] 마이페이지**
- **프로필 관리**: 닉네임, 프로필 공개/비공개 설정
- **활동 통계**: 포인트, 레벨, 참여 내역
- **제출물 관리**: 내가 제출한 프로젝트 한눈에 조회

**[ 확장 기능 3 ] 소셜 기능**
- **팀 초대 시스템**: 실시간 초대/신청 알림 (NotificationsFAB)
- **메시지 시스템**: 팀원/개인 간 채팅 모달
- **포인트 시스템**: 활동 기반 게이미피케이션 (랭킹 반영)

#### 전략 3: 프리미엄 UX/UI
- **Framer Motion**: 부드러운 애니메이션 (카드 호버, 페이지 전환)
- **다크 테마**: 개발자 친화적 디자인
- **반응형**: 모바일/태블릿/데스크톱 완벽 대응
- **Lucide Icons**: 일관된 아이콘 시스템

### 3.2 localStorage 키 설계

제공된 예시 데이터를 기반으로 다음과 같이 확장 설계:

| localStorage 키 | 초기 데이터 소스 | 설명 |
|-----------------|-----------------|------|
| `hackathons` | public_hackathons.json | 해커톤 목록 |
| `hackathon_details` | public_hackathon_detail.json | 해커톤 상세 (7개 섹션) |
| `teams` | public_teams.json | 팀 정보 |
| `leaderboards` | public_leaderboard.json | 리더보드 |
| `users` | *(자동 생성)* | 회원가입 사용자 |
| `currentUser` | *(로그인 시 저장)* | 현재 로그인 사용자 |
| `submissions` | *(빈 배열)* | 제출물 (사용자 추가) |
| `team_invites` | *(빈 배열)* | 팀 초대/신청 |
| `messages` | *(빈 배열)* | DM 메시지 |
| `team_ideas` | *(빈 배열)* | 팀 아이디어 보드 |
| `team_schedules` | *(빈 배열)* | 팀 캘린더 일정 |
| `team_resources` | *(빈 배열)* | 팀 리소스 |

**초기화 전략**:
```typescript
// 최초 접속 시 샘플 데이터를 localStorage에 주입

  localStorage.setItem('hackathons', JSON.stringify(sampleHackathons));
}
```

```typescript
export function writeToStorage<T>(key: string, value: T) {
  localStorage.setItem(key, JSON.stringify(value));
  window.dispatchEvent(new Event('storage-update')); // 커스텀 이벤트

useEffect(() => {
```

```typescript
function calculateLeaderboard(hackathonSlug: string): LeaderboardEntry[] {
  const submissions = getSubmissions(hackathonSlug);
  
  // 제출한 팀만 점수 부여
  const entries = submissions.map(sub => ({
    rank: 0, // 임시
    teamName: sub.teamName,
    score: Math.random() * 100, // 실제로는 평가 점수
    submittedAt: sub.submittedAt
  }));
  
  // 점수 내림차순 정렬 후 순위 부여
  entries.sort((a, b) => b.score - a.score);
  entries.forEach((entry, idx) => entry.rank = idx + 1);
  
  return entries;
}
```

#### 🚀 Feature 1: AI 기반 팀 매칭 알고리즘 (HIGH PRIORITY)

**목적**: 해커톤의 핵심 페인 포인트인 "팀 빌딩" 과정을 AI로 자동화하여 최적의 팀원 매칭 제공

**기능 상세**:
1. **사용자 프로필 확장**
   - 기술 스택 (React, Python, ML, Design 등)
   - 관심 분야 (Web, AI, Blockchain 등)

   - 활동 시간대 (타임존)
   - 경력 수준 (초급, 중급, 고급)

2. **매칭 알고리즘**
   ```typescript
   // src/services/aiMatching.ts
   
   interface UserProfile {
     userId: string;
     skills: string[];        // ["React", "TypeScript", "Node.js"]
     interests: string[];     // ["Web", "AI"]
     role: string;            // "Frontend Developer"
     lookingFor: string[];    // ["Backend", "Designer"]
     timezone: number;        // UTC+9
     experienceLevel: number; // 1-5
     hackathonsCompleted: number;
   }
   
   function calculateCompatibility(user1: UserProfile, user2: UserProfile): number {
     // 1. 스킬 매칭 (Jaccard Similarity)
     const skillIntersection = user1.skills.filter(s => user2.skills.includes(s));
     const skillUnion = [...new Set([...user1.skills, ...user2.skills])];
     const skillMatch = skillIntersection.length / skillUnion.length;
     
     // 2. 역할 보완성 (user1이 찾는 역할을 user2가 담당)
     const roleComplement = user1.lookingFor.includes(user2.role) ? 1 : 0;
     
     // 3. 타임존 호환성
     const timezoneMatch = Math.abs(user1.timezone - user2.timezone) <= 3 ? 1 : 0.5;
     
     // 4. 경력 균형 (너무 차이 나지 않게)
     const levelDiff = Math.abs(user1.experienceLevel - user2.experienceLevel);
     const levelMatch = levelDiff <= 2 ? 1 : 0.7;
     
     // 5. 관심사 공통점
     const interestIntersection = user1.interests.filter(i => user2.interests.includes(i));
     const interestMatch = interestIntersection.length / Math.max(user1.interests.length, 1);
     
     // 가중치 적용
     return (
       skillMatch * 0.25 +
       roleComplement * 0.35 +
       timezoneMatch * 0.15 +
       levelMatch * 0.10 +
       interestMatch * 0.15
     );
   }
   
   function findBestMatches(currentUser: UserProfile, allUsers: UserProfile[], topN = 10): MatchResult[] {
     const matches = allUsers
       .filter(u => u.userId !== currentUser.userId)
       .map(user => ({
         user,
         score: calculateCompatibility(currentUser, user),
         reasons: generateMatchReasons(currentUser, user)
       }))
       .sort((a, b) => b.score - a.score)
       .slice(0, topN);
     
     return matches;
   }
   
   function generateMatchReasons(user1: UserProfile, user2: UserProfile): string[] {
     const reasons: string[] = [];
     
     // 공통 스킬
     const commonSkills = user1.skills.filter(s => user2.skills.includes(s));
     if (commonSkills.length > 0) {
       reasons.push(`공통 스킬: ${commonSkills.join(', ')}`);
     }
     
     // 역할 보완
     if (user1.lookingFor.includes(user2.role)) {
       reasons.push(`${user2.role} 역할 매칭`);
     }
     
     // 타임존
     if (Math.abs(user1.timezone - user2.timezone) <= 1) {
       reasons.push('같은 시간대에서 활동');
     }
     
     // 경험치
     if (Math.abs(user1.experienceLevel - user2.experienceLevel) <= 1) {
       reasons.push('비슷한 경력 수준');
     }
     
     return reasons;
   }
   ```
