# 솔루션 설명 자료 (PPT 구성용 Draft 초안)

*본 문서는 PDF(PPT) 변환을 위한 스크립트 작성 파일입니다. 이 내용을 바탕으로 디자인된 PPT를 제작 후 PDF로 내보내시기 바랍니다.*

---

## [Slide 1: 타이틀]
**Hackathon Hub: 개발자와 기획자를 연결하는 원스톱 해커톤 플랫폼**
- 부제: Vibe 배포 해커톤 참가작 솔루션 설명서
- 팀 이름 및 로고

---

## [Slide 2: 문제의식 파악 (Why)]
- **문제점:** 현재 해커톤 참가자들은 해커톤 공지 파악(Notion 등), 팀빌딩(카카오톡/슬랙), 결과물 제출(구글 폼) 시 각각 다른 플랫폼을 사용해야 합니다. 
- **페인 포인트:** 분산된 정보로 인해 정작 중요한 '프로젝트 개발'에 몰입할 시간이 부족해집니다.

---

## [Slide 3: 솔루션 제안 (What)]
**올인원 생애주기 관리**
- '탐색 → 팀빌딩 → 개발 일정 관리 → 결과물 제출 → 리더보드 확인' 까지의 플로우를 단 하나의 서비스에서 커버합니다.
- 매력적이고 직관적인 사이트 디자인 (디자인 토큰 도입, Framer Motion 인터랙션 구현)을 통해 참가 독려 의지를 북돋습니다.

---

## [Slide 4: 핵심 기능 1 - 7개의 통합 탭 뷰]
**어디서든 한눈에 보는 해커톤 상세정보**
- 상세 페이지 내 7개의 Essential 탭 (개요, 평가기준, 일정, 상금, 팀, 제출, 리더보드) 구성.
- 각자의 데이터들이 로컬 스토리지에 동적 매핑되어 렌더링.

---

## [Slide 5: 핵심 기능 2 - 즉각형 팀 라운지 (Camp)]
**자유로운 매칭 파이프라인**
- `/camp` 를 통해 모집 중인 팀을 보고 연락망(URL)으로 즉시 연결.
- 직접 리더가 되어 부족한 포지션을 명시한 모집 공고를 바로 발행.

---

## [Slide 6: 개발 기술 스택 및 아키텍처 (How)]
- **Frontend Core:** React 18, Vite, Typecript
- **Design System:** Tailwind CSS, Framer Motion을 기반으로 한 `ui-ux-pro-max` 커스텀 스킬 적용 설계 (Darkmode & Vibrant)
- **Datastore (No-Backend):** Browser `localStorage` 데이터 시딩 기법으로 서버 리스펙 구동 테스트 최적화.
- **Deploy:** Vercel 플랫폼을 이용한 글로벌 CDN 배포 수행 완료.

---

## [Slide 7: 추후 발전 방향]
- 실제 데이터베이스 (BaaS 기반) 확장 모델 도입 기획
- 팀 내 채팅 및 다이렉트 푸시 알림 기능
- AI 기반 사용자 포트폴리오를 대조한 자동 팀 추천 솔루션
