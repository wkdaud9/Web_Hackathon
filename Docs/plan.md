# 🚀 서비스 기획서 (1차 제출용)

## 1. 서비스 개요
본 프로젝트는 **'해커톤 참여자 간의 소통 및 팀 빌딩을 돕는 통합 플랫폼 (Hackathon Hub)'** 입니다. 대규모 개발자 경진대회에서 필수적으로 요구되는 '팀 빌딩', '공지사항 확인', '프로젝트 제출', '결과 리더보드 확인' 등의 주요 플로우를 하나의 솔루션에서 제공함으로써 참가자(개발자, 디자이너, 기획자)들의 진입 장벽을 낮추고 온전히 프로젝트에 몰입할 수 있도록 돕습니다.

## 2. 페이지 구성 (Page Structure)
- **`/` (홈):** 전체 서비스로 진입할 수 있는 3개의 대형 GNB 모션 카드(해커톤 탐색, 팀 모집, 명예의 전당)를 제공합니다.
- **`/hackathons` (해커톤 목록):** 현재 열려있는 해커톤 목록과 태그, 상태 필터 기능을 통한 검색 기능을 제공합니다.
- **`/hackathons/:slug` (해커톤 상세):** 개요, 평가기준, 일정, 상금, 팀 현황, 결과물 제출, 리더보드라는 7개의 핵심 탭 인터페이스를 제공하여 해커톤 생애주기의 모든 니즈를 충족합니다.
- **`/camp` (팀원 모집 라운지):** 팀을 직접 개설하고 역할별 모집 공고를 내거나 오픈 카톡 등으로 연동하는 기능이 있습니다.
- **`/rankings` (명예의 전당):** 제출된 결과물과 리더보드를 시각화된 시상대 구조와 함께 확인합니다.

## 3. 시스템 구성 (System Architecture)
- **프론트엔드 프레임워크:** Vite(빌드 툴) + React 18 + TypeScript
- **라우팅 설정:** React Router v6
- **스타일링 및 애니메이션:** Tailwind CSS v3 (+ ui-ux-pro-max 디자인 스킬 연동), Framer Motion (마이크로 인터랙션)
- **상태 관리 및 데이터 스토리지:** 브라우저 내장 `localStorage`를 활용하여 백엔드 없이 모의 데이터를 영속적으로 CRUD(Create, Read, Update, Delete) 관리

## 4. 핵심 기능 명세
- **데이터 자동 시딩 (Seeding):** 앱 최초 구동 시 JSON 형식의 예시 자료 4종을 읽어 스토리지에 세팅하여 API 통신 없이 즉시 체험이 가능한 샌드박스 환경을 구축합니다.
- **다크 모드 및 모던 UI:** `ui-ux-pro-max` 디자인 시스템을 활용해 #0F172A 배경과 네온 그린(#22C55E) CTA의 Vibrant & Block-based 테마를 적용했습니다.
- **다이내믹 제출 및 필터링:** 프론트엔드 환경에서 즉각적인 결과물 제출 및 리더보드 최신화가 반영되며 무한뎁스 검색 필터가 동작합니다.

## 5. 주요 사용 흐름 (User Flow)
1. **[발견]** 사용자는 `/` 에 진입하여 진행중인 해커톤 현황을 확인 (`/hackathons` 필터 활용)
2. **[참가 준비]** 원하는 해커톤의 `/hackathons/:slug` 상세 정보 탭을 훑어보고 일정과 상금을 파악
3. **[팀빌딩]** '팀 현황' 탭이나 `/camp` 에서 팀 모집 공고를 등록하고 연락처(오픈채팅)를 통해 팀 매칭
4. **[결과물 릴리즈]** 해커톤 진행 후 상세 페이지 내 '제출' 탭을 통해 Github URL 또는 Docs URL을 입력해 결과물 저장
5. **[축하]** 점수 부여 후 `/rankings` 명예의 전당에서 리더보드 랭킹 탐색 및 타 참가자들의 결과물 레퍼런스 확인

## 6. 개발 및 개선 계획
- **팀 매칭 추천 알고리즘 (추후 고도화):** 참가자의 스킬셋(예: "프론트엔드", "Figma")을 분석하여 모집 중인 라운지를 자동으로 연결해주는 기능.
- **실제 백엔드(DB) 연동:** Supabase 또는 Firebase와 연동해 localStorage에 종속적인 구조를 글로벌 DB로 마이그레이션.
